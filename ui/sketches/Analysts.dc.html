Why estimates differ

  • Ships that switch off AIS are missed by anyone counting AIS alone.
  • Spoofed positions create crossings that never happened.
  • Satellite passes are days apart, so each pass is a snapshot.
  • Some figures include oil products and bypass pipelines; some do not.
