One network is shared by all of them; training rows per fold run from 59,805 to 222,941 (the macro run had 1,682 to 5,818). A series is scored in a fold only if it has 60+ monthly changes in that fold's training months, and outputs whose climatology CRPS is below 0.05 pp (a price that practically never moved, where any ratio to it is meaningless) are left out: `consumer_al_cp0731@6`, `consumer_al_cp0731@12`.

Skill = 1 − CRPS / CRPS of climatology (each output's training mean and spread), averaged over the outputs in the row; 0 is no better than climatology. `global, no oil` is the same network with its oil inputs set to 0, so `global` minus `global, no oil` is what knowing oil adds. `OLS, same inputs` is per-series least squares on all 26 network inputs; `OLS, small` uses 4 of them (own last change, Brent lags 0–2), which is all 80–280 months per series can support.
