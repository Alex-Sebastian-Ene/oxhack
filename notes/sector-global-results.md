# Industries by country: global network results

_Generated by `experiments/sector_global.py report --set sectors` on 2026-10-25 from 8 forward-chaining folds (2008-01..2025-10, 214 forecast origins), the folds of `notes/macro-global-results.md`. Fold files generated 2026-10-24T22:26:10+00:00 to 2026-10-24T23:51:59+00:00. Data: Eurostat `sts_inppd_m` (domestic producer prices) and `sts_inpr_m` (output, seasonally and calendar adjusted), FRED (BLS PPIs, Fed industrial production, IMF metal prices), fetched by `experiments/macro_data.py`; real and revised (not real-time vintages); nothing is synthetic. Every forecast here is a **what-if**: it is given the oil path that happened._

**Series scored:** 316 producer prices, 287 output, 9 world prices (36 countries). One network is shared by all of them; training rows per fold run from 45,736 to 158,740 (the macro run had 1,682 to 5,818). A series is scored in a fold only if it has 60+ monthly changes in that fold's training months.

Skill = 1 − CRPS / CRPS of climatology (each output's training mean and spread), averaged over the outputs in the row; 0 is no better than climatology. `global, no oil` is the same network with its oil inputs set to 0, so `global` minus `global, no oil` is what knowing oil adds. `OLS, same inputs` is per-series least squares on all 26 network inputs; `OLS, small` uses 4 of them (own last change, Brent lags 0–2), which is all 80–280 months per series can support.
